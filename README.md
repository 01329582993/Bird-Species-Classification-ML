# Bird-Species-Classification-ML

This repository contains a machine learning workflow for bird species classification using image data.

## Project Structure

- `notebooks/` — Jupyter notebooks for setup, preprocessing, feature extraction, model training, and comparison.
- `src/` — reusable Python modules for preprocessing, feature extraction, and utility functions.
- `dataset/` — dataset documentation and local dataset storage instructions.
- `results/` — saved model artifacts and evaluation outputs.
- `figures/` — plots, charts, and visualizations.
- `report/` — final report materials.
- `presentation/` — slides and presentation assets.

## Workflow

1. Run the notebooks in order from `00_Project_Setup.ipynb` to `07_Model_Comparison.ipynb`.
2. Keep shared processing code under `src/`.
3. Save generated results under `results/` and figures under `figures/`.

## Environment

Install dependencies with:

```bash
pip install -r requirements.txt
```
