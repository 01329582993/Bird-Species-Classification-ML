\begin{abstract}
Fine-grained image classification remains a challenging task in computer vision due to high intra-class variance and subtle inter-class differences. In this project, we investigate the classification of a 20-species subset from the Caltech-UCSD Birds-200-2011 (CUB-200-2011) dataset. We present a detailed evolutionary study of classification performance, transitioning from initial baselines using hand-crafted descriptors (Histogram of Oriented Gradients, Local Binary Patterns, and Multi-Colorspace Color Histograms) to a hybrid approach leveraging frozen deep visual embeddings from a pre-trained ResNet-18 model combined with classical classifiers. Our experiments demonstrate that while extensive feature engineering, bounding box cropping, and feature selection (ANOVA F-test) push classical ML models to a plateau around 35\%, the introduction of transfer-learned deep representations solves the representation bottleneck, yielding a dramatic accuracy boost and establishing a new pipeline for efficient, low-compute classification.
\end{abstract}

\section{Introduction}
\IEEEPARstart{F}{ine-grained} visual categorization (FGVC) involves distinguishing between sub-categories of a common class, such as different species of birds, models of cars, or types of aircraft. Unlike generic image classification, FGVC requires capturing highly localized and subtle discriminative visual features (e.g., beak shape, color patterns of crowns, and wing bars) while remaining robust to variation in pose, lighting, and background noise.

In this work, we focus on the Caltech-UCSD Birds-200-2011 (CUB-200-2011) dataset. To keep the computational overhead manageable for typical resource environments, we establish a target subset of 20 species using a keyword-based matching strategy targeting common families (e.g., Crow, Blackbird, Grebe, and Gull).

The project was structured across multiple iterative phases:
\begin{enumerate}
    \item \textbf{Phase 1: Project Setup and Initial Pipeline}: Setting up the dataset, class maps, and establishing raw feature extractions.
    \item \textbf{Phase 2: Baseline Modeling and Diagnostic}: Developing baseline classical classifiers and identifying reasons for initial low accuracy (11-17\%).
    \item \textbf{Phase 3: Preprocessing and Feature Engineering}: Implementing bounding box cropping, multi-colorspace color histograms, spatial pyramid structures, and feature normalization.
    \item \textbf{Phase 4: Dimensionality Management}: Exploring PCA vs. ANOVA-based feature selection (SelectKBest) to mitigate the curse of dimensionality.
    \item \textbf{Phase 5: Hybrid Deep Feature Integration}: Replacing hand-crafted features with semantic embeddings from a pre-trained ResNet-18 backbone while retaining classical classifiers.
\end{enumerate}

The remainder of this report describes the dataset preparation, method improvements, experimental results, and key findings.

\section{Dataset and Preprocessing Pipeline}
The CUB-200-2011 dataset contains 11,788 images of 200 bird species. Our pipeline focuses on a 20-species subset matching 20 family keywords, resulting in approximately 1,170 images. We utilize a stratified split of 70\% training, 15\% validation, and 15\% testing to maintain balanced class distributions across all evaluation phases.

\subsection{Bounding Box Cropping}
Initial diagnostic runs showed extremely low accuracy. The background clutter (branches, water, foliage) dominated the descriptors. To solve this, we parsed the raw coordinates from \texttt{bounding\_boxes.txt} and updated our preprocessing code in \texttt{src/preprocessing.py} to crop each image to the bird's tight bounding box before resizing. This step alone eliminated background bias, centering the models purely on the avian features.

\subsection{Standardization}
Features extracted from different descriptors have vastly different scales (e.g., HOG gradients vs. unnormalized histograms). We applied a robust \texttt{StandardScaler} to normalize the feature space prior to training, ensuring that high-magnitude dimensions did not dominate distance metrics in SVM and k-NN.

\section{Feature Extraction Methodologies}
We explored two paradigms of feature extraction: hand-crafted geometric/color descriptors, and transfer-learned deep representations.

\subsection{Hand-Crafted Feature Descriptors}
\begin{itemize}
    \item \textbf{Histogram of Oriented Gradients (HOG)}: Captures edge directions and local shapes. We transitioned from single-channel grayscale HOG to a multi-channel HOG computed over grayscale, Red, Green, and Blue channels.
    \item \textbf{Spatial Pyramid HOG}: To capture spatial layout, we extracted HOG features across a spatial pyramid consisting of the full image plus four quadrants ($2 \times 2$ grid), concatenating the regional descriptors.
    \item \textbf{Local Binary Patterns (LBP)}: Captures fine-grained surface textures. We upgraded from a single scale ($P=8, R=1$) to a multi-scale configuration combining fine texture ($R=1$) and coarse texture ($R=3, P=24$).
    \item \textbf{Multi-Colorspace Histograms}: To model color characteristics, we concatenated 32-bin histograms from RGB, HSV (Hue-Saturation-Value), and CIELAB spaces, yielding 9 color channels of high discriminative power.
\end{itemize}

\subsection{Deep Visual Embeddings (Strategy 1)}
To resolve the performance plateau of classical features, we replaced hand-crafted descriptors with deep features. We loaded a pre-trained ResNet-18 model and froze its parameters to act as a static feature extractor. The final fully connected classification layer was replaced with an \texttt{Identity} module, producing a dense 512-dimensional visual embedding for each bird crop. These embeddings capture high-level semantic abstractions trained on millions of images, providing a highly compact yet discriminative input for our classical classifiers.

\section{Classification and Hyperparameter Tuning}
We evaluated five classical classifiers using the extracted features:
\begin{enumerate}
    \item \textbf{Support Vector Classifier (SVC)}: Optimized with an RBF kernel, searching over $C \in [1, 10, 50, 100]$ and $\gamma \in [\text{'scale'}, \text{'auto'}, 0.001]$.
    \item \textbf{k-Nearest Neighbors (k-NN)}: Evaluated using Euclidean and Manhattan distances, varying $k$ and using distance-weighted voting.
    \item \textbf{Decision Tree (DT)}: Structured with entropy/gini criteria and depth constraints.
    \item \textbf{Random Forest (RF)}: Tuned using varying tree counts and depth limitations.
    \item \textbf{Logistic Regression (LR)}: Regularized with L2 penalty, utilizing a one-vs-rest configuration.
\end{enumerate}

\subsection{Deep Feature Classification Performance}
Transitioning to deep visual embeddings (ResNet-18) resolved the feature representation bottleneck. By extracting the 512-dimensional embeddings, the classical classifiers were able to learn much cleaner decision boundaries. The classification performance jumped significantly, achieving accuracies in the range of 70\% to 80\% on the 20-species CUB subset, demonstrating the enormous value of transfer learning for fine-grained computer vision tasks.

\section{Discussion and Implementation Notes}
During development, several critical environment and logic bugs were successfully diagnosed and patched:
\begin{itemize}
    \item \textbf{Nested Directory Bug}: Under Google Colab, automatic cloning created nested paths like \texttt{/content/Bird-Species-Classification-ML/.../ML}. We added a self-healing setup cell (\texttt{COLAB\_SETUP\_CELL}) that automatically detects the Colab runtime, cleans nested folders, and resets the directory context.
    \item \textbf{Module Cache issues}: Python's default import system cached older versions of \texttt{src/preprocessing.py} in Colab notebook sessions. We resolved this by prefixing imports with \texttt{importlib.reload(src.preprocessing)}.
    \item \textbf{Model Dimension Mismatch}: When changing feature representations, loaded pickled models would crash with \texttt{ValueError} due to mismatching expected inputs. We patched \texttt{07\_Model\_Comparison.ipynb} to validate model input dimensions against the active dataset, automatically deleting and rebuilding outdated models inline.
\end{itemize}

\section{Conclusion}
In this project, we successfully built and optimized a machine learning pipeline for fine-grained classification on a 20-species subset of CUB-200-2011. Our findings confirm that while classical feature engineering (HOG, Color, LBP) can be pushed to around 35\% accuracy using techniques like bounding box cropping and spatial pyramids, it is severely limited by hand-crafted descriptor constraints. Incorporating a pre-trained ResNet-18 visual feature extractor provides a massive leap in accuracy (exceeding 70\%) while maintaining the speed and low computational footprint of classical ML classifiers.
